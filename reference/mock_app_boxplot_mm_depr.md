# Mock mm boxplot app with deprecated visit_var and default_visit arguments

Mock mm boxplot app with deprecated visit_var and default_visit
arguments

## Usage

``` r
mock_app_boxplot_mm_depr(update_query_string = TRUE, anlfl_flags = FALSE)
```

## Arguments

- update_query_string:

  automatically update query string with app state

- anlfl_flags:

  indicates that the input data contain analysis flag variables or not
